# 💕 Ask Her Out - The Impossible NO Button

A fun, interactive website to ask someone out with a playful twist: **the NO button runs away from your cursor!**

## ✨ Features

- **Dark Gothic Theme**: Mysterious and romantic atmosphere with purple gradients and glowing pink accents
- **Impossible NO Button**: The NO button intelligently escapes your cursor when you try to click it
- **Smooth Animations**: Beautiful entrance animations and confetti celebration
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Easy to Deploy**: Simple HTML, CSS, and JavaScript - no build process needed

## 🎮 How It Works

1. The website displays a romantic question with two buttons: **YES** and **NO**
2. The **YES** button is easy to click and triggers a celebration with confetti
3. The **NO** button runs away whenever your cursor gets too close (within 100px)
4. The button stays within the viewport boundaries so it can't escape completely
5. When you click YES, confetti and celebratory emojis rain down! 🎉
